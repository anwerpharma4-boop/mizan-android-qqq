# ميزان — مشروع Android عبر GitHub

## إنشاء APK
1. أنشئ مستودعًا جديدًا في GitHub باسم `mizan-android`.
2. ارفع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع.
4. وافق على تشغيل GitHub Actions إذا طُلب منك ذلك.
5. افتح عملية **Build Mizan Android APK** بعد اكتمالها.
6. من قسم **Artifacts** نزّل `mizan-android-debug-apk`.
7. فك ضغط الملف الذي نزلته، وستجد `app-debug.apk`.

## ملاحظات
- هذا APK تجريبي للتثبيت المباشر (Debug APK)، وليس إصدار Google Play موقّعًا.
- التطبيق يحتفظ بالبيانات في تخزين WebView المحلي على الجهاز. لا تمسح بيانات التطبيق أو تحذفه إذا أردت الاحتفاظ بها.
- الرسوم والخطوط في ملف HTML الحالي تعتمد على موارد خارجية (Chart.js وGoogle Fonts)، لذلك تحتاج اتصال إنترنت لظهورها/تحميلها أول مرة.
- معرّف التطبيق: `com.anwer.mizan`.
